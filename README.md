# نادي — منصة إدارة الأندية الرياضية

منصة SaaS سعودية متكاملة: اشتراكات، كاشير، محاسبة بالقيد المزدوج، فواتير متوافقة مع
هيئة الزكاة، موارد بشرية، فروع متعددة، وبوابات ذاتية للموظفين والمشتركين.

## الأقسام

| القسم | المحتوى |
|---|---|
| لوحة الإدارة | مؤشرات الأداء والحضور والإيرادات |
| الاستقبال | تحضير بالباركود والبصمة والبوابة، وبحث فوري |
| الكاشير | بيع منتجات واشتراكات، مخزون، ست طرق دفع |
| الورديات | فتح وتقفيل الصندوق مع ترحيل الفروقات محاسبياً |
| الاشتراكات | باقات، تجديد، تجميد، ملف عضو كامل |
| العملاء المحتملون | تسجيل الزوار ومتابعتهم حتى الاشتراك |
| رسائل واتساب | قوالب وتنبيهات تلقائية وصندوق صادر |
| الحصص | جدولة، سعة لحظية، قائمة انتظار |
| العروض | أكواد خصم بنسبة أو مبلغ ثابت |
| الفواتير الضريبية | UBL 2.1، سلسلة هاش، QR بترميز TLV |
| المحاسبة | دليل حسابات، دفتر يومية، ميزان مراجعة، قوائم مالية، إقرار ضريبي، أعمار ذمم |
| التقارير | إيرادات ومصروفات وساعات الذروة ومعدل التسرب |
| الموارد البشرية | رواتب وبدلات وتأمينات ونهاية خدمة وحضور بالباركود والموقع |
| الإعلانات | خطابات داخلية مع تتبع الاطلاع |
| الفروع | فرع لكل موقع بمشتركيه وحساباته |

## التشغيل محلياً

```bash
npm install
npx prisma migrate dev
npm run db:seed
npm run dev
```

ثم افتح <http://localhost:3000>

**حسابات تجريبية** (كلمة المرور `123456`): `admin@nadi.sa` مزود الحل ·
`owner@club.sa` مالك · `branch@club.sa` مدير فرع · `accountant@club.sa` محاسب ·
`hr@club.sa` موارد بشرية · `reception@club.sa` استقبال · `staff@club.sa` موظف ·
`member@club.sa` مشترك

## النشر على سيرفر

قاعدة البيانات محلياً SQLite، وفي الإنتاج PostgreSQL. التبديل بأمر واحد:

```bash
npm run db:postgres
```

### متغيرات البيئة المطلوبة

```
DATABASE_URL=postgresql://user:pass@host/db?sslmode=require
DIRECT_URL=postgresql://user:pass@host/db?sslmode=require
AUTH_SECRET=<ولّده بـ openssl rand -base64 32>
```

`AUTH_SECRET` إلزامي في الإنتاج — التطبيق يرفض الإقلاع بدونه لأن الجلسات موقّعة به.

### خيار ١: منصة تدعم Next.js (الأسهل)

اربط المستودع بالمنصة واضبط متغيرات البيئة أعلاه، ثم:

```bash
npm run db:deploy
```

### خيار ٢: أي سيرفر عبر Docker

```bash
docker build -t nadi .
docker run -p 3000:3000 --env-file .env nadi
```

### خيار ٣: سيرفر تقليدي (VPS)

```bash
npm ci
npm run db:postgres
npm run db:deploy
npm run build
npm start
```

## ملاحظات على الامتثال

- **الفوترة الإلكترونية**: مستند UBL 2.1 وسلسلة هاش (PIH) وعدّاد (ICV) ورمز QR
  منفَّذة. التوقيع الإلكتروني والربط ببوابة «فاتورة» يتطلبان شهادة CSID من الهيئة.
- **واتساب**: يعمل بوضع الرابط اليدوي فوراً. الإرسال التلقائي يتطلب حساب
  WhatsApp Business معتمداً من Meta.
