# نادي — منصة إدارة الأندية الرياضية

منصة SaaS سعودية لإدارة الأندية: اشتراكات، تحضير، حجوزات حصص، ورسائل واتساب.

## الجاهز حالياً

- **شاشة الاستقبال** — بحث فوري، تحضير بضغطة، حالات الاشتراك بالألوان (فعّال / قرب ينتهي / منتهي)، تجديد، وتذكير واتساب برسالة جاهزة
- **جدول الحصص** — 7 أيام، سعة لحظية، حجز مع قائمة انتظار تلقائية، وتتبع مصدر كل حجز (تطبيق / استقبال / منصات خارجية)

## التقنيات

Next.js 16 · Prisma 6 · SQLite (تطوير) · Tailwind CSS 4 · عربي RTL بالكامل

## التشغيل

```bash
npm install
npx prisma migrate dev
npx tsx prisma/seed.ts
npm run dev
```

ثم افتح http://localhost:3000

## خارطة الطريق

1. ✅ الأساس: اشتراكات، تحضير، حجوزات
2. المدفوعات: تابي وتمارا + فوترة زاتكا + ربط محاسبي
3. الأتمتة: WhatsApp Business API + ربط أجهزة البصمة والأساور
4. السوبر أب: تطبيق جوال للأعضاء + API عام للمنصات الخارجية
