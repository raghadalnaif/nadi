# الوسيط — ربط أجهزة الحضور بمنصة URGYM

برنامج صغير يعمل **داخل شبكة النادي**. يقرأ البصمات والبطاقات من الجهاز
محلياً ويرسلها للمنصة عبر الإنترنت.

```
جهاز البصمة (شبكة النادي)  →  الوسيط  →  URGYM
```

الجهاز لا يحتاج اتصالاً خارجياً ولا عنوان IP عاماً — الوسيط وحده يتصل بالإنترنت.

## الماركات المدعومة

| الماركة | البروتوكول | الحالة |
|---|---|---|
| **ZKTeco** | TCP 4370 — أحداث حية | الأشيع سعودياً |
| **Hikvision** | ISAPI عبر HTTP — بث مستمر | بوابات وكاميرات |
| **Suprema BioStar 2** | REST — استعلام دوري | أنظمة مؤسسية |
| **قارئ عام** | HTTP محلي | أي قارئ باركود أو USB |

> **تنبيه مهم:** المحوّلات مكتوبة وفق البروتوكولات المنشورة لكل ماركة،
> ولم تُختبر على جهاز فعلي. توقّع تعديلاً بسيطاً عند أول تشغيل حسب موديل
> جهازك. أرسل لي سجل `agent.log` وأضبطه لك.

## التشغيل

### ١. مفتاح API من المنصة

الإعدادات ← الربط مع التطبيقات ← **مفتاح جديد** ← فعّل صلاحية `checkin`.
انسخ المفتاح فوراً (يُعرض مرة واحدة).

### ٢. الإعداد

```bash
cp config.example.json config.json
```

عدّل `config.json`: ضع مفتاح API، وعنوان كل جهاز في الشبكة المحلية،
واحذف الأجهزة التي لا تملكها.

### ٣. التشغيل

```bash
node agent.js
```

على ويندوز: ثبّت [Node.js](https://nodejs.org) ثم شغّل الأمر من مجلد الوسيط.

### ٤. التشغيل الدائم

على لينكس:

```bash
npm i -g pm2
pm2 start agent.js --name urgym-agent
pm2 save && pm2 startup
```

على ويندوز: استخدم Task Scheduler مع خيار «عند بدء التشغيل».

## ماذا يحدث عند كل قراءة

1. الجهاز يقرأ البصمة ويرسل رقم المستخدم للوسيط
2. الوسيط يرسله للمنصة مع مصدره (بصمة / بوابة / سوار)
3. المنصة تتحقق من الاشتراك:
   - **فعّال** → يُسجَّل الحضور
   - **منتهٍ أو مجمّد** → يُرفض (إن فعّلت «منع دخول منتهي الاشتراك»)
4. النتيجة تُسجَّل في `agent.log`

## انقطاع الإنترنت

الحضور يُحفظ في طابور محلي ويُرسل تلقائياً عند عودة الاتصال — **لا يضيع أي حضور**.

## ربط رقم العضو بالجهاز

رقم المستخدم في جهاز البصمة يجب أن يطابق **رقم العضوية** أو **الباركود**
في المنصة. أسهل طريقة: استخدم رقم العضوية نفسه عند تسجيل البصمة.
